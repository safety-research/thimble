# Agent runs (made up)

Twenty-four runs of a coding agent on six small tasks. Every name and message here is invented, for trying
thimble browser.

- `results.csv`: one row per run: its task, its outcome (`merged` or `failed`), the cause of a failure, the
  number of events and the minutes it took.
- `runs/run-NN.jsonl`: one event per line: the task, the agent's messages, its tool calls and their results,
  a review, and the end.
