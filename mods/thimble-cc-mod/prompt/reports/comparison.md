A comparison matrix sets the cases side by side, such as runs, agents, sessions or conditions, one row each, against the measures that tell them apart, one column each, so a reader can compare any two cases or scan one measure down all of them. Choose the few measures the findings turn on rather than every column a card has, and order the rows so the pattern shows, such as by outcome. Each cell is a short value or phrase taken from a card and cited to it. A one-line takeaway stands above the grid and a legend for any marks under it.

Write the grid as a Markdown table under a `## ` heading that states the pattern, the first column naming each case, at most six columns so it fits the panel. Then a short section per measure that needs explaining, each with the card it comes from as a figure.
