---
name: Comparison matrix
description: A grid of the cases, such as runs, agents or sessions, against the measures that tell them apart, each cell taken from a card.
renderer: page
---

A comparison matrix sets the cases side by side, so that a reader can compare any two cases, or scan one measure down all of them.

Each case is one row, for example a run, an agent, a session or a condition. Each measure that tells the cases apart is one column. Each cell is a short value or phrase taken from a card. A one-line takeaway stands above the grid, and a legend for any marks stands under it. The grid may be wider than the page, and then the page scrolls sideways.

Choose the few measures that the findings turn on, not every column a card has. Order the rows so that the pattern shows, for example by outcome.
