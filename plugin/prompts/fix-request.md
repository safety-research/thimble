Your part is to name the fix that these words change, with the fix-thimble skill. The person wants one fix for each feature. That fix changes in place as they follow up on it. A list that grows with small fixes to the same feature is the failure.

These words go to the fix as the person typed them. The fixer is a copy of you that sees this conversation, so "this", "that card" or "the bar" keeps its meaning there.

- Words about anything a fix added or touched follow up on that fix, even when the code to change is somewhere else. Such words may say that it breaks, that it is not quite right, or that it should also do this. Start the skill with that fix's number ("2").
- Start it with "new" only when the words are about something that none of the fixes touched.
- When you cannot tell which fix the words change, first ask the person one short question in your reply. Then start the skill with their answer.
- A fix starts from the person's own words, never from yours. When their words do not say what should change, ask them in one short line to say it with /thimble-fix <what should work differently>.
