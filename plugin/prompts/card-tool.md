Draw an interactive card under this call, or a new version of a card you drew.

1) Data: write the rows as a JSON file, in this folder or in the temp folder `$TMPDIR` (<temp folder>), with code that reads the records (Python, jq, ...), and give its path as `data`; a path may start with `$TMPDIR/`. The file holds a list of rows (JSON records). Give each row a "ref" to the line that shows its value, such as "runs.jsonl#L13"; for a command an agent ran, that is the line with the command's output. thimble reads the file and keeps the rows; they do not come back to you.

2) `view` is JavaScript (no import, export, require, `$` or globalThis, and no call of eval or Function) defining `function view(props, surface)`. It returns a drawing made with `const { Box, Text, Button } = surface.elements`, each called as a function with Ink props and `children`: Box (flexDirection, gap, width, height, padding*, margin*, borderStyle "round"|"single", borderColor, justifyContent, alignItems), Text (color and backgroundColor as "#rrggbb", bold, dimColor, underline, inverse, wrap: "truncate-end"; nest Texts for runs of color in one line), Button (key, onPress, plain: true for a bare clickable label, children: strings or Text). Any characters draw: █ ▀ ▄ half-blocks, ⣿ braille dots, box lines. `props.rows` is all the rows, `props.query` the live search text or null. `surface.columns` is the width; `surface.onPointer(fn)` (call it in view each time; fn gets {type, x, y} in cells, type "down" is a click) lets any cell be clicked.

3) State: `surface.state` (undefined at first) and `surface.setState(next)` (the whole state, plain JSON); the person's state is kept when the card redraws later. Compute everything (filter, sort, search, statistics) in view on each call.

4) Keys: `const keys = "sn/"` lists the keys the card takes while the prompt box is empty (letters, digits or signs; never arrows, and never v, which thimble keeps for itself); `function onKey(key, surface, props)` gets each one and calls surface.setState. `/` also starts a live search the person types in the prompt box: props.query changes per keystroke, Enter keeps it, emptying the box clears it.

5) The call draws the card and returns a text copy of what it drew (its first state), or the view's error. `actions` (optional) tries keys and clicks in order, each {"key": "s"}, {"click": "words on a Button"} or {"click": [x, y]} (cells, as onPointer gets them), and returns the text copy after each one; then the card goes back to its first state. To change a card, call card again with its `id`: the new version takes the place of the old one, and no second card is drawn. Without `id`, the call draws a new card.
