Draw an interactive card, or a new version of a card you drew. The card shows where this call stands in the conversation, above the words you write after the call, so when you write about it, name it by its title.

1) Data: write the rows as a JSON file, in this folder or in the temp folder `$TMPDIR` ({{TMPDIR}}), with code that reads the records (Python, jq, ...), and give its path as `data`; a path may start with `$TMPDIR/`. The file holds a list of rows (JSON records), an object with a "rows" list, or JSON Lines. thimble keeps a copy of the rows for the card. The call tells you how many rows the card read, their columns and the first row, so you do not have to print the rows to check the file.

2) `view` is JavaScript that defines `function view(props, surface)`. It runs in a sandbox with no files, no network and no timers (no import, export, require, `$`, globalThis or process, and no call of eval or Function). It returns a drawing made with `const { Box, Text, Button } = surface.elements`, each called as a function with Ink props and `children`: Box (flexDirection, which is "row" when you do not give it, flexGrow, flexShrink, flexWrap, gap, width and height in cells or as "50%", padding*, margin*, borderStyle "round"|"single", borderColor, justifyContent, alignItems), Text (color and backgroundColor as "#rrggbb", bold, dimColor, underline, inverse, wrap: "truncate-end"; nest Texts for runs of color in one line), Button (onPress, plain: true for a bare clickable label, children: strings or Text). Any characters draw: █ ▀ ▄ half-blocks, ⣿ braille dots, box lines. The terminal's background may be light or dark: words with no color given read on both, and a color you give must be clear on white and on black. Say what a color means with a sample of it (`█ survived`), not by its name. `props.rows` is all the rows, `props.title` the title, `props.query` the live search text or null, and `surface.columns` the card's width in cells now. The width changes, for example when the analyst opens a side pane, so lay out from `surface.columns`, not from fixed widths. Keep the card to about 30 rows, so that its header and the row the analyst picks are on the screen together: show a page of rows and let keys move through them. A drawing of thousands of elements does not draw.

3) State: `surface.state` (undefined at first) and `surface.setState(next)` (the whole state, plain JSON). thimble keeps the analyst's state when the card draws again, also in a resumed session. Compute everything (filter, sort, search, statistics) in view on each call.

4) Input: `const keys = "sn/"` lists the keys the card takes while the prompt box is empty (letters, digits or signs, but not {{KEPT}}, which thimble keeps for itself); `function onKey(key, surface, props)` gets each one and calls surface.setState. thimble lists the card's keys under it, so the view need not. With `/` in keys, the analyst types a live search in the prompt box: props.query changes at each keystroke, Enter keeps it, and an empty box ends it. A click on a Button runs its onPress, wherever the Button is drawn, so make each thing the analyst can click a Button. `surface.onPointer(fn)` (call it in view each time) gets each click on the card as {type: "down"} and then {type: "up"}, with x and y in cells from the card's top left corner; use it only where the place of the click is the point, such as a cell of a grid, because a header that wraps moves every row below it.

5) The call draws the card and returns what it read and a text copy of what it draws, or the view's error. `actions` (optional) tries keys, clicks and searches in order, each {"key": "s"}, {"click": "words on a Button"}, {"click": [x, y]} (cells, as onPointer gets them) or {"search": "words"}, and returns the text copy after each one; then the card goes back to its first state. Try each way in that the card offers the analyst. To fix or adjust a card, call card again with its `id`: the new version takes the place of the old one, and no second card is drawn. Without `id`, the call draws a new card; a new question gets a new card.
