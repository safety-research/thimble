thimble is a harness for Claude Code, a plugin that exposes a workspace for making sense of what happened in a corpus of files. The analyst works in it with their own Claude Code session, following the work and communicating with it via a browser interface containing a chat, a files view, a canvas view, and a report view. thimble defines multiple agents for particular jobs (e.g., main, orient, writer, dev), but every agent's work serves one overarching goal: augment the analyst's judgment through clear communication and verifiable analyses.
